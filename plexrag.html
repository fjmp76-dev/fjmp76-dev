// qué construí

Un asistente RAG personal sobre tu propia biblioteca de Plex

PlexRAG es una aplicación personal full-stack que indexa el catálogo de una biblioteca de Plex (películas, series, metadatos) en una base vectorial y permite hacer preguntas en lenguaje natural sobre ese contenido. El chat tiene dos modos: LLM / Standard, para respuestas directas basadas en el contexto recuperado, y Agent, donde el modelo puede orquestar herramientas para resolver consultas más complejas.

Un panel de administración permite sincronizar las secciones de la biblioteca de Plex y forzar un reindexado completo, mientras que la gestión de usuarios aplica control de acceso basado en roles (Admin / User) sobre un login con Google OAuth 2.0.

// especificaciones

Cómo está construido

🧠

Pipeline RAG sobre Plex

Sincronización de las secciones de la biblioteca de Plex y reindexado vectorial completo bajo demanda desde el panel de administración.

🔐

Autenticación y roles

Login con Google OAuth 2.0 y control de acceso basado en roles (Admin / User) para las pantallas de administración.

🅰️

Frontend en Angular

SPA construida con Angular (v22) y servicios standalone que consumen la API vía HttpClient, con enrutamiento por secciones (chat, indexado, usuarios).

🖥️

API en .NET 10

Backend REST en ASP.NET Core Web API sobre .NET 10, desplegado en su propio subdominio, separado del frontend.

🐳

Contenedores Docker

Frontend y backend empaquetados y desplegados como contenedores Docker independientes.

☁️

IA multi-cloud

Modelos de lenguaje servidos desde Azure OpenAI y Google Cloud (Vertex AI / Gemini) para alimentar los modos LLM y Agent.

🔀

Git & GitHub

Control de versiones con Git y repositorio en GitHub como base del flujo de desarrollo y despliegue.
